## 🚀 Краткое описание

**User Backup Manager** — это автоматизированная система резервного копирования пользовательских данных для Windows. Приложение обеспечивает централизованное управление резервным копированием профилей пользователей с использованием Windows Task Scheduler.

## 🎯 Назначение

Основные цели приложения:

1. **Автоматизация** — автоматическое создание резервных копий без участия пользователя
2. **Централизованное управление** — обновление скриптов и конфигурации из сетевой папки
3. **Надежность** — продолжение работы при временной недоступности сети
4. **Простота** — минимальное взаимодействие с пользователем

## ⭐ Ключевые функции

### 🔄 Автоматическое резервное копирование
- Запуск через Windows Task Scheduler
- Два триггера: при входе пользователя и ежедневно
- Автоматическое создание ZIP-архивов

### 📁 Поддержка различных источников
- Стандартные папки Windows (Desktop, Documents)
- Пользовательские директории через конфигурационный файл
- Гибкая система исключений файлов

### 🔧 Централизованное управление
- Обновление скриптов из сетевой папки
- Единая конфигурация для всех пользователей

### 🛡️ Контроль ресурсов
- Ограничение максимального размера источников
- Проверка свободного места
- Ограничение времени выполнения

## 🚀 Быстрый старт

### Установка
```cmd
Просто запустите: Install-UserBackup.cmd
```

### Что происходит после установки?
✅ Файлы копируются в `%LOCALAPPDATA%\ASUP\UserBackup\`  
✅ Задача создается в Планировщике заданий Windows  
✅ Резервное копирование начинается автоматически

### Расписание работы
- **Через 3 минуты после входа** в систему (настраивается)
- **Ежедневно в 01:00** (настраивается)

### Где хранятся архивы?
```
D:\_BackUp_\[Имя пользователя]\
├── 20261019_090000_Desktop.zip
├── 20261019_090000_Documents.zip
└── ...
```

## 📥 Подробная установка

### Простой запуск
```cmd
Install-UserBackup.cmd
```

### Расширенный запуск
```powershell
powershell.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File "Install-UserBackup.ps1" -ConfigPath "BackupConfig.json" -Diagnostic
```

### Процесс установки

1. **Проверка зависимостей**
   - Проверка наличия Windows PowerShell 5.1+
   - Валидация синтаксиса всех скриптов

2. **Копирование файлов**
   Все файлы копируются в: `%LOCALAPPDATA%\ASUP\UserBackup\`

3. **Регистрация задачи**
   Создается задача в Windows Task Scheduler с параметрами:
   - Имя: `Backup Task`
   - Путь: `\ASUP\User BackUp Manager\`
   - Триггеры: при входе + ежедневно

4. **Валидация**
   Проверка созданной задачи и запись результата в журнал

## ⚙️ Конфигурация

### Основной конфигурационный файл (`BackupConfig.json`)

```json
{
  "Install": {
    "LocalSubdirectory": "ASUP\\UserBackup"
  },
  "Task": {
    "Name": "Backup Task",
    "Path": "\\ASUP\\User BackUp Manager\\",
    "ManagedNames": ["Backup Task", "User BackUp Manager", "ASUP User Backup"],
    "DelayMinutes": 3,
    "DailyRunTime": "01:00",
    "ExecutionTimeLimitHours": 6
  },
  "Update": {
    "NetworkPath": "\\\\FS-01\\Scripts\\UserBackupManager / ",
    "WorkerFileName": "Backup-UserData.ps1",
    "LauncherFileName": "Launcher-UserBackup.ps1",
    "TaskRegistrarFileName": "Register-UserBackupTask.ps1",
    "ConfigFileName": "BackupConfig.json",
    "ContinueOnFailure": true,
    "ShowWarningOnFailure": true
  },
  "Backup": {
    "RootPath": "D:\\_BackUp_",
    "HideRootFolder": true,
    "CopiesToKeep": 2,
    "MaxSourceSizeMB": 700,
    "ScheduleMode": "Daily",
    "WeeklyDay": "Monday",
    "SafetyReserveMB": 64,
    "ExcludeMasks": ["*.tmp", "~$*", "*.mp3", "*.wav", "*.mp4", "*.avi"]
  }
}
```

### Ключевые параметры

#### Задача планировщика (`Task`)
- **`Name`**: Имя задачи в планировщике
- **`Path`**: Путь к задаче (должен начинаться и заканчиваться `\`)
- **`DelayMinutes`**: Задержка после входа пользователя (1-1440 минут)
- **`DailyRunTime`**: Время ежедневного запуска (формат HH:mm)

#### Обновление (`Update`)
- **`NetworkPath`**: Сетевая папка для обновлений
- **`ContinueOnFailure`**: Продолжать работу при ошибке обновления
- **`ShowWarningOnFailure`**: Показывать предупреждение при ошибке

#### Резервное копирование (`Backup`)
- **`RootPath`**: Корневая папка для архивов
- **`CopiesToKeep`**: Количество сохраняемых копий
- **`MaxSourceSizeMB`**: Максимальный размер источника в МБ
- **`ScheduleMode`**: Режим расписания (`Daily` или `Weekly`)

### Пользовательские директории (`LocalDirectoriesToBackup.lst`)

```
:: Включить или отключить список - True / False
True

Pictures
Links
Downloads\Important
```

**Формат**:
1. Первая строка: комментарий (необязательно)
2. Вторая строка: `True` (включено) или `False` (отключено)
3. Последующие строки: относительные пути от `%USERPROFILE%`

### Автоматическое использование
После установки система работает полностью автоматически:
1. **При входе пользователя** (с настраиваемой задержкой)
2. **Ежедневно в заданное время**

### Ручной запуск
```powershell
# Запуск лаунчера вручную
%LOCALAPPDATA%\ASUP\UserBackup\Launcher-UserBackup.ps1
```

```powershell
# Проверка зарегистрированной задачи
Get-ScheduledTask -TaskName "Backup Task" -TaskPath "\ASUP\User BackUp Manager\"

# Просмотр журнала
Get-Content "$env:LOCALAPPDATA\ASUP\UserBackup\Launcher.log" -Tail 10
```

## 🔄 Обновление из сети

### Централизованное обновление
Система поддерживает обновление ключевых компонентов из сетевой папки:

**Обновляемые файлы**:
- `BackupConfig.json` - Конфигурация
- `Backup-UserData.ps1` - Рабочий скрипт
- `Register-UserBackupTask.ps1` - Регистратор задач
- `LocalDirectoriesToBackup.lst` - Список директорий
- `Launcher-UserBackup.ps1` - Сам лаунчер
- `Install-UserBackup.ps1` - Скрипт установки
- `Uninstall-UserBackup.ps1` - Скрипт удаления

### Процесс обновления

1. **Проверка доступности** сети и сетевой папки
2. **Загрузка файлов** во временное хранилище
3. **Валидация** синтаксиса PowerShell скриптов
4. **Сравнение** с текущими версиями (хеш SHA-256)
5. **Транзакционное обновление** с поддержкой отката
6. **Перерегистрация задачи** с новыми параметрами

### Настройка сетевой папки

1. Создайте сетевую папку (например, `\\FS-01\Scripts\UserBackupManager\`)
2. Разместите в ней актуальные версии файлов
3. Настройте права доступа:
   - **Чтение**: Все пользователи
   - **Запись**: Только администраторы

## 🗑️ Удаление

### Простое удаление
```cmd
Uninstall-UserBackup.cmd
```

### Расширенное удаление
```powershell
Uninstall-UserBackup.ps1 -ConfigPath "BackupConfig.json" -WhatIf
```

### Процесс удаления

1. **Чтение конфигурации** проекта и установленной версии
2. **Поиск связанных задач** по `Task.ManagedNames` и маркеру АСУП
3. **Остановка и удаление** найденных задач
4. **Удаление локальных файлов** из `%LOCALAPPDATA%\ASUP\UserBackup\`

**Важно**: Архивы из `D:\_BackUp_\` не удаляются автоматически!

## 🔍 Диагностика

### Журналы системы

**Основные журналы**:
- `%LOCALAPPDATA%\ASUP\UserBackup\Launcher.log` - Журнал лаунчера
- `D:\_BackUp_\[Пользователь]\UserBackup.log` - Журнал резервного копирования

**Формат записей**:
```
2026-10-19 09:00:00.123 [INFO] Launcher started. Version=2026.09.15.1.
2026-10-19 09:00:05.456 [INFO] Update completed successfully.
```

### Проверка состояния

```powershell
# Проверка задачи планировщика
$task = Get-ScheduledTask -TaskName "Backup Task" -ErrorAction SilentlyContinue
if ($task) {
    Write-Host "Задача найдена:" -ForegroundColor Green
    Write-Host "  Состояние: $($task.State)"
    Write-Host "  Путь: $($task.TaskPath)"
} else {
    Write-Host "Задача не найдена" -ForegroundColor Red
}

# Проверка свободного места
$freeSpace = (Get-PSDrive -Name D).Free / 1GB
Write-Host "Свободно на диске D: $([math]::Round($freeSpace, 2)) GB"
```

### Распространенные проблемы

#### Задача не запускается
1. Проверьте состояние задачи: `Get-ScheduledTask -TaskName "Backup Task"`
2. Проверьте журнал: `Get-Content "$env:LOCALAPPDATA\ASUP\UserBackup\Launcher.log"`

#### Ошибки обновления
1. Проверьте доступность сетевой папки
2. Убедитесь в правильности `Update.NetworkPath`
3. Проверьте права доступа к сетевой папке

#### Недостаточно места
1. Освободите место на целевом диске
2. Увеличьте параметр `Backup.SafetyReserveMB`
3. Измените `Backup.RootPath` на диск с большим объемом свободного места

## 📋 Технические требования

### Системные требования
- **Операционная система**: Windows 7 SP1 / Windows Server 2012 R2 или выше
- **PowerShell**: Версия 5.1 или выше
- **.NET Framework**: 4.5 или выше
- **Место на диске**: Зависит от объема резервных копий + 64 МБ резерв

### Рекомендуемые конфигурации
- **Процессор**: 1 GHz или выше
- **Оперативная память**: 512 МБ (минимум), 2 ГБ (рекомендуется)
- **Дисковое пространство**: В 2 раза больше размера резервируемых данных
- **Сеть**: 100 Мбит/с или выше для обновлений из сетевой папки

### Ограничения
- **Максимальный размер источника**: 700 МБ по умолчанию (настраивается)
- **Количество сохраняемых копий**: 2 по умолчанию (настраивается)
- **Максимальное время выполнения**: 6 часов по умолчанию (настраивается)
