# Quick Start Guide - User Backup Manager

## 🚀 Быстрый старт за 5 минут

### 1. Установка
```cmd
Просто запустите: Install-UserBackup.cmd
```

### 2. Что происходит после установки?
✅ Файлы скопированы в `%LOCALAPPDATA%\ASUP\UserBackup\`  
✅ Задача создана в Планировщике заданий  
✅ Резервное копирование начнется автоматически

### 3. Когда работает резервное копирование?
- **Через 3 минуты после входа** в систему
- **Ежедневно в 01:00** (настраивается)

### 4. Где хранятся архивы?
```
D:\_BackUp_\[Ваше имя пользователя]\
├── 20261019_090000_Desktop.zip
├── 20261019_090000_Documents.zip
└── ...
```

### 5. Как проверить, что всё работает?
```powershell
# Проверка задачи
Get-ScheduledTask -TaskName "Backup Task"

# Просмотр журнала
Get-Content "$env:LOCALAPPDATA\ASUP\UserBackup\Launcher.log" -Tail 10
```

## 📁 Что копируется по умолчанию?

| Папка | Что содержит |
|-------|-------------|
| **Desktop** | Файлы с рабочего стола |
| **Documents** | Документы пользователя |

## ➕ Как добавить свои папки?

1. Откройте файл:  
   `%LOCALAPPDATA%\ASUP\UserBackup\LocalDirectoriesToBackup.lst`

2. Добавьте пути (относительно вашей папки пользователя):
   ```
   Pictures
   Downloads\Important
   Projects
   ```

3. Сохраните файл

## ⚠️ Важные ограничения

- **Максимальный размер одной папки**: 700 МБ
- **Сколько копий хранится**: 2 последние версии
- **Исключаемые файлы**: аудио, видео, временные файлы

## 🔧 Быстрые настройки

### Изменить время ежедневного запуска
В файле `BackupConfig.json` измените:
```json
"Task": {
    "DailyRunTime": "22:00"  // В 22:00 вместо 01:00
}
```

### Увеличить количество копий
```json
"Backup": {
    "CopiesToKeep": 5  // Хранить 5 копий вместо 2
}
```

## 🆘 Быстрая помощь

### Проблема: "Недостаточно места"
**Решение**: Освободите место на диске D: или измените `Backup.RootPath`

### Проблема: Архивы не создаются
**Решение**: Проверьте журнал `Launcher.log` на ошибки

### Проблема: Хочу отключить на время
**Решение**: В планировщике заданий отключите задачу "Backup Task"

## 📞 Куда обращаться?

1. **Сначала проверьте журналы**
2. **Обратитесь в отдел АСУП** с:
   - Именем пользователя
   - Временем проблемы
   - Записями из журналов

## 🔄 Обновление системы

Система обновляется автоматически из сетевой папки.  
Для принудительного обновления запустите лаунчер:
```powershell
%LOCALAPPDATA%\ASUP\UserBackup\Launcher-UserBackup.ps1
```

## 🗑️ Удаление

Для полного удаления:
```cmd
%LOCALAPPDATA%\ASUP\UserBackup\Uninstall-UserBackup.cmd
```

**Внимание**: Архивы не удаляются автоматически!
